# PolyMeet

PolyMeet 是本機會議工作區，支援麥克風與分頁音訊錄音、即時逐字稿、雙語翻譯、音檔補轉及 AI 會議紀錄。

## 啟動

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

開啟終端機顯示的網址。開發指令會同時啟動 Vite 與本機後端。正式版本可先執行 `npm run build`，再執行 `npm start`（或 `npm run preview`）並開啟 `http://127.0.0.1:3001`。執行 `npm run typecheck`、`npm test` 與 `npm run format:check` 可分別檢查型別、執行測試及檢查格式。開發伺服器固定使用 5173 埠；若該埠被占用，請先停止占用它的服務。

在介面設定中填入 API 金鑰與各功能的模型 ID；預設只在目前瀏覽器分頁保存金鑰；可在設定中選擇記住金鑰，跨分頁保留。也可複製 `.env.example` 為 `.env`，設定後端備用金鑰，重新啟動服務後生效。後端只監聽本機。可用模型依供應商帳號權限而異，呼叫服務可能產生費用。

會議、逐字稿、會議紀錄及錄音片段保存在瀏覽器 IndexedDB。錄音每五秒保存一次，切換離開頁面時會要求保存目前片段；錄音或保存期間離開會顯示瀏覽器警告。異常中斷時最後一段仍可能尚未寫入，請定期下載重要錄音。即時連線短暫中斷時，音訊會排隊等待重連；長時間中斷或停止時若無法送出，介面會提示下載錄音補轉。

選擇「麥克風 + 分頁音訊」時，分享視窗中須選擇提供音訊的來源並啟用音訊分享；實際選項取決於瀏覽器及作業系統。上傳大於 23 MiB 的音檔時，瀏覽器會先解碼並切為十分鐘 WAV 片段，因此需要足夠記憶體。上傳的原始音檔也會保存在本機；Google 音檔補轉使用 Files API，完成後會嘗試刪除雲端暫存檔，清理失敗時會提示。

若轉錄服務未回傳逐句時間，逐字稿會標示「片段起點」；播放時會從該上傳片段的開頭開始，而非精確的發話位置。

使用轉錄、翻譯或 AI 會議紀錄時，相關音訊或文字會傳送至所選的供應商。OpenAI 翻譯與會議紀錄請求會關閉 Responses API 的回應儲存。音檔補轉中斷時，保留目前選取的音檔並重新開始，可從尚未完成的片段繼續。

雙語會議可選兩種語言並開啟投影字幕；投影畫面的 `F` 切換全螢幕，`+`／`-` 調整字級。詳見 `PLAN.md`。

一般會議可設定逐字稿語言；雙語會議的語言設定也會用於音檔轉錄。選擇繁體或簡體中文時，系統會要求服務使用指定字形，並在適用時校正輸出。繁簡中文同時選用時，逐字稿依服務標註的字形校正，未標註時採用語言一。中文搭配日文時，系統校正可辨識的中文字形，保留無法判定語言的共用漢字。已保存的舊逐字稿和會議紀錄不會自動修改。需要中文校正的翻譯與紀錄會在整段生成完成後顯示，以避免逐字轉換造成詞義錯誤。
